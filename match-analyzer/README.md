# Match Analyzer — Tactical Football Intelligence & Spatial Analytics

An editorial, publication-grade football analytics platform by **Jerein Sam Thomas**.

## Overview
Match Analyzer is an interactive tactical intelligence publication that deconstructs modern football matches through data analytics, optical tracking, and spatial frameworks.
